Class gestionDeReserva

Gestiona las reservas de vehículos en el sistema.

Coordina la creación y cierre de reservas, verifica disponibilidad de vehículos, actualiza su estado y procesa el mantenimiento.

  • Agrega una nueva reserva al sistema.

    Parameters

      Reserva a agregar.

    Returns void

    Throws

cerrarReserva

  • cerrarReserva(reserva): number

  • Cierra una reserva completada.

      • Actualiza el kilometraje del vehículo, llama a finalizarAlquiler() para actualizar su estado y retorna el costo.

    Parameters

    • reserva: reserva

      Reserva a cerrar.

    Returns number

    Costo total del alquiler.

    Throws

    Propaga error si el vehículo no está en estado 'En Alquiler'. *

    Example

    const costo = gestionDeReservas.cerrarReserva(reserva);
    console.log(`Total a pagar: $${costo}`);
